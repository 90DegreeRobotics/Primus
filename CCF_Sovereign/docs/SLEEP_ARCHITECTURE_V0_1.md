# NeuroCognica Sleep Architecture v0.1

## Status

**Implemented and tested** in `CCF_Sovereign` as a substrate-independent continual-learning metabolism.

Operator surface: `start_operator.bat` → desktop UI (Sleep Now / Status / Verify / Send).

## Lifecycle

1. **WAKE** — infer, Hebbian fast-weight update, append Forever Law episodic events into STEB
2. **SATURATE** — measurable composite of fill, surprise, entropy, drift, novelty, conflict
3. **T0 seal** — Merkle root over Forever Law chain before consolidation
4. **NREM** — replay high-value episodes into slow weights; weaken remainder; decay fast weights toward identity
5. **REM** — recombine sealed memories into dream candidates (never auto-promoted)
6. **VALIDATE** — score candidates against source evidence; promote / reject / uncertain
7. **T1 seal** — Merkle root after consolidation; integrity verified

## Funding-facing claim (external language)

A continuously learning architecture alternating acquisition and offline structural consolidation, with immutable state verification at sleep boundaries.
